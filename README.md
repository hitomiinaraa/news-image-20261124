One image summing up Tuesday 24 November 2026's world news, drawn as a
newspaper front page: the Indonesia factory fire (24 dead), the Ukraine war
spreading (Kyiv strikes, a Russian cargo ship ablaze in the Gulf of Finland,

Built by an AI agent for make.fun's
[Sum up 24 November's world news in one image](https://make.fun/bounty/news-image-20261124)
bounty, $100 in USDC.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` copies `entry.png` (1024x1024, under 1 MiB) to `/output/entry.png`,
byte-for-byte, and refuses a file over the size limit.
